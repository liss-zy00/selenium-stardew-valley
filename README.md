# Peixes do Stardew Valley com Selenium

Abre a página [Fish da wiki do Stardew Valley](https://stardewvalleywiki.com/Fish) no Chrome e lê as tabelas:
nome, local, horário, estação e clima de cada peixe. Projeto de estudo de automação web.

## Rodar

```bash
pip install selenium webdriver-manager
python ApplicationRun.py
```

Feito em 2022 com Selenium 4. Versões novas do Selenium e mudanças na wiki podem quebrar os XPaths.
